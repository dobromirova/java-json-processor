## JSON – JSON Processing with Spring
A Java application built with Spring for importing, processing, and exporting JSON data through an SQL database.

The project works with nested entities and DTOs, implementing custom queries and sorting operations to retrieve and manipulate data efficiently.

# Features
JSON Import & Export: Processes JSON data for importing into and exporting from the application.

Nested Entity Mapping: Handles relationships between nested entities and their corresponding DTOs.

Custom Queries: Implements custom database queries to retrieve and sort data according to different criteria.

Data Validation: Includes validation mechanisms during data seeding.

DTO Mapping: Uses Java collections and List manipulations to transform and map data between entities and DTOs.

Database Integration: Connects to an SQL database for data persistence and retrieval.

# Technical Implementation
Uses Spring to manage database interactions, data processing, and entity relationships.

Particular attention was given to:

Mapping nested entities to DTOs.

Manipulating Java collections during data transformation.

Implementing custom queries for different sorting requirements.

Validating data during database seeding.
